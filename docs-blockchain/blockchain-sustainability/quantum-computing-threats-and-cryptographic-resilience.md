### Core Cryptographic Vulnerabilities

* <mark style="background-color:red;">**Public-Key Compromise**</mark>: Shor's algorithm breaking asymmetric encryption (RSA, ECC) used for signatures and identities (PKI).
* <mark style="background-color:red;">**Hash Function Degradation**</mark>: Collision and preimage risks altering data integrity and block validation.

[#the-2-main-threats-to-blockchain-security](../blockchain-architecture/quantum-computing/#the-2-main-threats-to-blockchain-security "mention")



### Network & Operational Attacks

* <mark style="background-color:red;">**Quantum-accelerated compute**</mark> could allow malicious actors to perform&#x20;
  * 51% attacks&#x20;
  * chain reorganization
  * data theft
  * double-spends
  * manipulate oracle data feeds&#x20;
  * decrypt private smart-contract state logic
* <mark style="background-color:red;">Supply-chain disruption</mark>: tampered provenance / authenticity records
* <mark style="background-color:red;">Smart-contract exploitation</mark>: unauthorized access, financial loss, manipulation of contract terms



### Ecosystem Risks

* <mark style="background-color:red;">**Rapid tech advances**</mark>: capabilities outpacing defences&#x20;
* <mark style="background-color:red;">**Difficulty detecting/monitoring quantum attacks**</mark>: fast — rapid execution, hard-to-monitor quantum attacks due to unique properties of quantum attacks



### Wider System, Economic & Legal Impacts

* <mark style="background-color:red;">**Economic losses**</mark>: financial damage, crypto value impact, disrupt blockchain-based businesses
* <mark style="background-color:red;">**Reduced trust in blockchain**</mark>: user/public confidence erosion
* <mark style="background-color:red;">**Legal/regulatory challenges**</mark>: liabilities (for data breaches, inadequate security practices), compliance gaps
* <mark style="background-color:red;">**Erosion of competitive advantage**</mark>: vulnerable blockchain solutions



### Post-Quantum Cryptography (PQC) & Migration

#### Migration Challenges

**Moving to quantum-safe standards** carries&#x20;

* network fragmentation risks & compatibility issues&#x20;
  * when incompatible quantum-resistant solutions are adopted
* algorithm migration complexity
* inadequate quantum-safe standards: slow standardization/adoption
* migration risks: temporary vulnerabilities during switchover, need for consensus among network participants
* key size trade-offs&#x20;
* implementation complexity across decentralized nodes
