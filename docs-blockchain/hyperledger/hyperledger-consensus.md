# \*Hyperledger: Consensus

## Hyperledger: Consensus

> network of nodes validates the block of transactions and provides a **guaranteed ordering of transactions**

* Confirms accuracy of all transactions in a block according to endorsement and consensus policies
* Agrees on the order and precision(correctness) of execution results
* Depends on smart contract layer to verify the exact (correctness) order of transaction in a block
* Make use of **permissioned voting based consensus**&#x20;



Consensus Properties

* Safety : each node guarantees tje same sequence of inputs &#x20;
* Liveness
